# Model weights

Place these files in this directory to enable image analysis:

- `best_model_dno.keras` — TensorFlow/Keras skin-type classifier (approximately 13 MiB).
- `skin_classifier.pth` — PyTorch acne classifier (approximately 94 MiB). The loader also supports the filename `skin_classifier.pt`.

Model weights are excluded from the source repository. Obtain the compatible weights from the project maintainers; downloading an arbitrary model with the same filename will not work.

For distribution, model files can be provided separately after their publication and licensing have been confirmed.
